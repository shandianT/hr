# 面前追问简报采用分阶段披露

下一轮面试官在提交独立评价前，只看到与本轮评分卡相关的证据缺口、待验证事实和合规的建议问题，默认看不到前轮总分、整体结论、面试官身份化意见或推进/淘汰决定。我们接受少量上下文重复，以降低锚定、从众和敏感信息扩散；需要处理跨轮问题时，在独立评价提交后再向有权限的人披露最小必要的前轮依据。

## Consequences

- 面前简报不是前轮报告，也不得复制完整逐字稿或候选人无关敏感信息。
- 每条建议问题要说明对应评分卡维度或证据缺口，并通过禁用特征、诱导性和适用范围校验。
- 例外披露必须有目的、权限、字段范围、时间和审计记录，不能由模型自行扩大。
- 面试官接受、编辑或忽略建议问题的反馈只能改进简报质量，不能直接修改画像或成为候选人的负面标签。
