# 终面评估包是不可变编译物，不是实时拼接页面

终面评估包必须钉住每个必需轮次的当前轮次完成件、有效豁免和证据版本，编译后形成不可变版本；任一输入被替代、撤销、删除或过期时，旧包立即失效并重新经过完整性校验。我们不采用“打开页面时实时拼最新数据”的做法，因为它无法证明最终决策人当时看到的材料、不能稳定审计，也会让输入变化静默改写决策依据。

## Consequences

- 同样的输入清单必须得到同样的业务内容 hash；重编译不能覆盖旧版本。
- `FINAL_ASSESSMENT_READY` 只引用一个当前有效包，包失效时案件回到 `INTERVIEWING` 等待补全或重编译。
- 已失效包保留为只读历史依据，但旧链接和旧审阅任务不能支持新的最终决定。
- 包编译器可以生成摘要，但不能解决跨轮问题或生成录用/淘汰建议。
