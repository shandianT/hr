# 时段提案和候选人选择不等于面试预定

时段提案只表达当前约束下可供选择的时段，候选人选择只表达预约意图；只有确定性控制面确认当前预约修订所需的日历、会议和邀请写入均获得版本匹配的有效回执后，才能提交面试预定事实。我们不采用“候选人点击即已排期”或“外部日历是唯一真相”，因为并发占用、部分成功、响应丢失和迟到回调会造成双重邀请或旧预约复活。

## Considered Options

- 候选人点击时立即显示已排期：体验快，但无法处理执行失败和并发冲突。
- 完全以外部日历为真相：连接器简单，但无法稳定关联案件修订、权限和补偿。
- 内部不可变修订加外部回执提交：多一个提交边界，但能审计、对账和幂等恢复。

## Consequences

- 一个面试会话最多有一个当前有效预定；外部重复资源进入对账与补偿，不能形成第二个业务预定。
- 改期提交成功前旧预定继续有效；新预约修订失败不得让会话看似没有安排。
- 迟到回调必须校验动作、预约修订和外部资源版本，只能补偿或留历史，不能恢复旧修订。
- 一轮包含多个必需会话时，只有全部必需会话均有当前有效预定，轮次才投影为已排期。
