# 招聘助手 V1 产品全貌与架构｜交付说明

> 交付日期：2026-08-21

## 1. 做了什么

本交付包用于让业务人员快速理解招聘助手 V1，并让编码 AI 按当前三人分工独立执行。

- `招聘助手V1_产品全貌与分工_人类版.md`：3 分钟理解产品、流程、分工和验收。
- `招聘助手V1_AI执行契约.md`：给 Codex、Claude Code 等编码 Agent 的执行约束。
- `diagrams/招聘助手V1_总架构流程图.mmd`：可编辑 Mermaid 图源。
- `diagrams/招聘助手V1_总架构流程图.svg`：文档嵌入版本。
- `diagrams/招聘助手V1_总架构流程图.png`：直接预览和发送的图片版本。

## 2. 关键决策

1. 正式 V1 只做“飞书简历 → 自动筛选评估 → HR 人工复核”，因为当前目标是先把核心功能做好。
2. 飞书招聘是唯一人才档案源，因为官网和 BOSS 简历最终都要在同一条主链路处理。
3. BOSS 自动化保持 `SPIKE_ONLY`，因为当前只验证自动打招呼和简历信息抓取能否稳定实现。
4. 使用固定接口汇总三方工作，而不是合并各自内部实现，因为这样可以并行开发和独立验收。

3. 企业真实飞书租户、真实岗位、真实简历附件和模型端到端路径仍需验证。
