# 招聘 Agent：简历筛选 Demo

解压交付包后，先打开 `resume_screening_demo.html`。仓库中的同一文件名为 `prototype/招聘Agent_核心功能2_画像匹配与部门决定Demo.html`。

这是第一版用于确认产品形态的简历筛选 Demo。默认页面只回答三件事：

1. 这个岗位在找什么；
2. 这份简历有哪些可回到原文的依据、哪些仍未知；
3. 当前用人负责人要做什么决定。

建议先体验默认的“正常筛选”场景，然后分别尝试：

- `进入一面`：进入下一阶段，但不会由 Agent 自动替人决定；
- `稍后复核`：填写原因和回看时间，催办停止；
- `本岗位不推进`：记录人工决定，但不会在这个 Demo 中自动向候选人发送拒信。

页面中的版本、SLA、Agent 活动和安全回执都放在“运行详情”中，不影响第一次理解主任务。页面下方的“测试其他情况”可以查看低证据、禁用信号、材料变化、超时、错误收件人与越权等安全分支。

所有候选人、岗位、简历、判断和回执均为合成数据。该 Demo 不连接真实邮箱、ATS、模型、身份系统或消息通道，不会产生任何真实外部效果。
