# 招聘 Agent 核心功能 1 Demo

双击 `招聘Agent_核心功能1_简历收件Demo.html` 即可打开，不需要安装软件或连接网络。

建议按这个顺序体验：

1. 选择「正常简历 · 自动开案」，点击「自动演示」，看一份附件如何通过五道门变成 ApplicationCase。
2. 选择「邮件 + ATS 重复到达」，确认只附加来源、不重复建案。
3. 选择「共享联系方式 · 身份冲突」，提交一次必要人工判断，再看 Agent 从检查点自动恢复。
4. 选择「岗位 / 批次不唯一」，体验选择路由或要求补充信息。
5. 选择「加密附件」与「简历内提示注入」，查看安全停止与零工具、零外发边界。

`招聘Agent_产品形态Demo_v1.html` 是从简历收件到终面评估包的全流程产品形态预览。

包内全部是虚构合成数据，不读取真实邮箱、ATS、本机文件或候选人资料，也不代表真实连接器或生产发布已经完成。
