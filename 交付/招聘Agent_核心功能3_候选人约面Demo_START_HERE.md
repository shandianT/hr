# 招聘 Agent 核心功能 3：候选人约面 Demo

## 先看什么

双击包内的 `scheduling_demo.html`。

默认只看三步：

1. 候选人选择时间；
2. Agent 确认日历、会议和邀请；
3. 三项都确认后才显示“面试已安排”。

选中时间后，页面会先明确显示“现在还不是已预定”。录制选择在最后的折叠区，默认不替候选人选择；选择“不录制”不影响预约。

## 建议体验顺序

1. 选择第一个时间并提交；
2. 看“正在确认”阶段的三项资源状态；
3. 等页面自动进入“面试已安排”；
4. 展开录制选择，选择“不录制”并保存；
5. 展开“测试其他情况”，查看改期、旧回调、响应丢失、暂停和错误收件人等安全分支。

## 包内文件

- `scheduling_demo.html`：可直接双击运行的候选人约面 Demo；
- `implementation_spec.md`：bounded 实施范围与公共接口；
- `acceptance_record.md`：已证明/未证明及当前测试快照；
- `START_HERE.md`：本说明。

## 证据边界

本包全部使用虚构数据和合成回执，不连接真实日历、会议、邮箱、候选人身份或录制系统。它证明产品状态与合成行为边界，不证明真实集成、真人可用性、法务批准或生产发布。
