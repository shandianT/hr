# Claude 原型设计包清单

生成日期：2026-08-10  
用途：供 Claude 从零设计招聘 Agent 高保真可点击原型

## 首先阅读

- `Claude原型设计任务书.md`：设计目标、用户、页面、关键流程、危险分支与验收标准。
- `招聘Agent产品落地总方案.md`：完整产品策略、阶段、团队、指标和风险。
- `产品方案总册.md`：用户提供的原始方案来源，仅作背景材料；与后续规格冲突时以后续规格和红线为准。

## 产品规格

- `招聘Agent_G1_MVP_PRD.md`：单轮面后证据闭环。
- `招聘Agent_G1a_工程开工包.md`：G1a 模块、命令、动作和异常边界，偏工程输入。
- `招聘Agent_G1b_终面评估包_PRD.md`：多轮串联、面前简报和终面评估包。
- `招聘Agent_G2_收件筛选约面_PRD.md`：收件、路由、匹配、部门决定、约面、采集与 G1 交接的当前产品规格。
- `招聘Agent_G2_需求追踪矩阵.md`：64 条 FR 与 28 个危险/正常验收场景的对应关系。
- `招聘Agent_G2_产品规格验收记录.md`：只证明文档一致性与边界，不证明功能已开发。
- `招聘Agent_G2产品规格实施计划.md`：G2 规格形成过程和完成记录，不作为高于 PRD 的权威来源。

## 统一语言与控制边界

- `CONTEXT.md`：统一领域语言。
- `招聘Agent_领域与事件规格.md`：案件、轮次、会话、动作、异常和版本规则。
- `0001`–`0008` ADR：关键架构/产品决策，尤其注意“时段提案不等于预定”和“录制告知不等于采集授权”。

## 进度、放行与追踪

- `招聘Agent推进看板.md`
- `招聘Agent_Gate0执行包.md`
- `招聘Agent_G1a_需求追踪矩阵.md`
- `招聘Agent_G1b_需求追踪矩阵.md`
- `招聘Agent_G2_需求追踪矩阵.md`

这些文件用于理解真实进度和验收红线，不代表功能已经开发。

## 有意不包含

- 旧的 `招聘Agent控制塔_逻辑原型.html`：用户已否定其设计，为避免锚定不放入本包。
- 旧原型验收记录：只证明旧原型的内部逻辑检查，不应影响新设计方向。
- JSON Schema、lint 脚本和本地学习日志：对原型视觉/交互设计不是必要输入。
- 任何真实候选人、邮箱、日历、会议、录音或凭据数据。
